# Logomocja

Logomocja is a benchmark for AI coding agents. Its reference app implements the Logo-inspired drawing task given to each agent.

## Language

**Benchmark**

An evaluation of AI coding agents building Logomocja from a versioned brief. It records build outcomes and independent language conformance.

**Benchmark attempt**

A recorded try at a benchmark task. It may produce scored results or end in failure, interruption, or a setup blocker.

**Benchmark protocol**

The task brief, generation environment, and scoring suites used for an attempt. Attempts under the same protocol can be compared using their shared measures.

**Reference app**

The maintained Logomocja implementation used to validate conformance cases and produce expected drawings.

**Studio**

The part of the reference app where visitors write and run Logo programs and inspect the resulting 2D or 3D drawings.
