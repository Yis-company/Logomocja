## Scope

Logomocja studio: the whole single-page app (studio, examples, challenges, reference). Visitor mode: **Operate** (the reference page is a Read sub-surface inside the same world). Build path: code-led (Operate surface; no image generation available).

## Audience and task

Polish learners (children, adult beginners, returning nostalgics) write a short Logo program, run or step it, watch the turtle draw in 2D or 3D, fix errors reported in Polish, solve challenges and share. Constraints: offline static site, hash routing, phone + desktop, light/dark.

## Direction contract

THESIS: The drawing area is a classroom wall chart (plansza dydaktyczna): a solid ink title band, a figure, and a numbered key. It refuses the category default of a grey IDE with a canvas bolted on.

OWN-WORLD: Chart paper ground, slightly cool and green-tinted, never cream. Green-black printing ink for text and the app header. Flat spot inks taken from the language's own colours: chart green #16866a (2D), ultramarine #2b6fb3 (3D), ochre #c1763d (challenges), trunk brown #6b4f2a (reference; changed from violet #a478c0 after the detector flagged violet headings as an AI-palette tell). Vermilion is used for errors only. Archivo condensed caps for chart titles, Archivo at normal width for UI, JetBrains Mono for code and readouts. Flat fills, 1px rules, no gradients, no faked paper or wood.

STORY: The learner sees their code beside a chart of what it draws, presses Uruchom, watches the turtle trace the figure, reads which ink drew which part in the key, and fixes any error by reading the Polish message at the marked spot.

FIRST VIEWPORT: Desktop 1440×900. A 52px green-black header holds the wordmark and the navigation (Pracownia, Przykłady, Zadania, Pomoc), with the theme and shortcuts buttons on the right. The left panel (~36%) holds the 2D/3D switch and the file menu, then a toolbar with Uruchom (primary, in the mode ink), Krok, Pauza and Reset and the speed slider, then the editor with line numbers, then the status line. The right side (~64%) is the chart: a 56px title band in the mode ink with the program's name in condensed caps and the view controls; the canvas with the turtle and numbered callouts; a 44px key band with ink swatches, segment counts and the live turtle readout. On a phone, the chart sits above the code and the toolbar stays reachable.

Signature move: numbered wall-chart callouts with leader lines, pinned to each ink's first stroke and keyed to the legend band. Signature motion: the stroke is drawn progressively behind the turtle at the chosen speed.
