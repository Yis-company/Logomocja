# Studio surface
Mode: Operate. Primary task: edit a Logo program, execute it, inspect its geometry. The product brief explicitly delegates decisions without an interview. Built code-first; no image-generation or delegated agents used.

## Direction contract
THESIS: A welcoming geometry workbench: examples, readable code and a large live drawing share one desktop workspace. The drawing, rather than an introduction, explains the product.
OWN-WORLD: Paper white #fcfcfa, warm shell #f4f4ef, graphite #252b28, forest teal #16866a, pale mint selection #e5f1e9. Familiar sans controls, monospace code, fine dividers, compact rounded buttons. Daylight learning at a desk motivates a light default that follows the system.
STORY: Load a real example, understand the short program, run or step, and see how one change transforms the shape. Work is saved locally. Mistakes point back to the exact token.
FIRST VIEWPORT: A slim brand/navigation header; a 240px example library; a 390px editor with execution actions; the remaining width is a gridded canvas with a teal rosette, mode toggle and camera controls. A quiet bottom strip contains turtle coordinates and running state. Signature interaction: execution highlights the corresponding source line while the turtle extends its geometric trail.
FORM: Three-pane studio, chosen from desktop split workspace, stacked notebook and full-canvas command drawer. User delegated the visual choice; concept roll recorded during verification, with no question page as explicitly instructed; seed:332e72127af4e04a. Standard navigation collapses to a library drawer on phones, then editor and canvas stack.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
